# RSM–머신러닝 하이브리드 LME 가격 예측 연구

**동남전자부품(주) × 동아대학교 산업경영공학과 산학협력**
지도교수: 신상문 교수님 | 참고논문: *Demand Forecasting of PO price using RSM and SVM* (Chimkeaw, 2017, 동아대)

---

## 연구 개요

기존에 구축한 LME 알루미늄 가격 예측 시스템을 발전시켜, 참고 논문의
**RSM(반응표면분석)–머신러닝 하이브리드** 방법론을 우리 데이터
(구리·환율·유가 → LME, 108개월)에 적용하고 비판적으로 검증한 연구.

핵심 질문: **"논문의 방법이 우리 데이터에서도 통하는가?"**

---

## 비교한 4가지 예측 방법

| 방법 | 설명 |
|---|---|
| RSM 단독 | 외부변수를 2차 다항식으로 LME 직접 예측 |
| 직접 예측 | ML(SVR/XGBoost/LSTM)이 LME 직접 예측 |
| β 예측 | ML이 RSM 계수(β)를 예측 → RSM 식으로 예측 *(논문에 없는 신규 시도)* |
| 2단계 예측 | 유가→구리→LME 순차 예측 *(논문 원본 방식)* |

평가지표: MAE · RMSE · MAPE · R² · D-stat(방향성 정확도)

---

## 핵심 발견

**1. 논문과 다른 결과 — 그리고 그 이유 규명**
논문은 "결합모델이 항상 최고"라 결론했으나, 우리 데이터에선 RSM 단독이
대부분 우수. 원인은 데이터의 경제적 성격 차이 — 논문은 생산사슬(인과),
우리는 상관관계(경기 공통요인). **방법론의 적용 조건을 밝힌 것이 기여.**

**2. β 예측의 근본적 한계**
RSM 계수가 시간에 따라 불규칙하게 요동침(환율² 변동계수 40.26).
"ML로 β 예측"은 계수 안정성 가정에 의존 → 우리 데이터엔 부적합.

**3. 최적 방법 = 예측기간 × 시장국면의 함수**
구간 분리 분석 결과: 안정기는 RSM 단독, 급등기는 2단계, 조정기는 직접 예측.
단일 방법이 모든 상황을 지배하지 않음.

**4. 데이터 증강의 효과 (수업 내용 연계)**
분포기반 증강이 소표본 한계를 완화 (XGBoost 8.23%→5.82%).
단, 증강 기법도 데이터·모델에 맞게 선택 필요.

**종합 결론: "방법에 절대 강자는 없다. 상황마다 검증해서 선택해야 한다."**

## 파일 구성

**분석 모듈**
- `rsm_hybrid.py` — RSM 회귀식(1/2/3차), 시나리오 1·2, Model 5 결합
- `step_forecast.py` — 2단계 예측 (논문 원본 방식)
- `method_advisor.py` — 방법 검증·권장 시스템
- `period_analysis.py` — 구간 분리 분석
- `augmentation.py` — 데이터 증강 실험
- `run_experiment.py` — 통합 실험 실행

**대시보드**
- `research_app.py` — Streamlit 연구 대시보드 (7개 섹션)
- `precomputed.json` — 미리 계산된 실험 결과

**문서**
- `연구노트.md` — 판단 기록 및 논문 작성용 정리
- `sample_multivariate.csv` — 데이터 (108개월)

## 실행 방법

**대시보드 (권장)**
```
pip install streamlit plotly pandas numpy
streamlit run research_app.py
```

**개별 실험 (터미널)**
```
pip install numpy pandas scikit-learn xgboost tensorflow
python run_experiment.py      # 방법 비교
python period_analysis.py     # 구간 분리
python augmentation.py        # 데이터 증강
```
